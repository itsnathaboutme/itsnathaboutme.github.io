Five spreadsheet formulas I use every week

Real examples from seven years of tracking training budgets, exam schedules, and project data at OffSec.

I spent seven years at Offensive Security building and maintaining spreadsheet tools for live training delivery and exam operations. These five formulas show up in almost every tracker I build — not because they are the flashiest, but because they solve real coordination problems without needing a developer.

1. VLOOKUP with IFERROR — pull instructor data without breaking the sheet

When I managed 16 exam proctors, I kept a roster sheet and a schedule sheet. Rather than copy-paste instructor details into every row, I pulled them in with VLOOKUP. Wrapping it in IFERROR meant a missing name never broke the whole table — it just showed a dash.

Formula
=IFERROR(VLOOKUP(A2, Roster!$A:$D, 3, FALSE), "—")

A2 — the proctor ID in the schedule sheet
Roster!$A:$D — the full roster table, locked with $ so it doesn't shift when you copy the formula down
3 — return the third column (email, in this case)
FALSE — exact match only
IFERROR — if nothing is found, show a dash instead of an error

2. COUNTIFS — count slots by status and region without a pivot table

During peak exam periods I needed a live count of how many slots were confirmed, pending, or missed — broken down by region. COUNTIFS lets me do that in one cell, no pivot table required.

Formula
=COUNTIFS(D:D, "Confirmed", E:E, "APAC")

D:D, "Confirmed" — only count rows where the Status column says Confirmed
E:E, "APAC" — and only where the Region column says APAC
Add more pairs to filter by additional columns — no limit.

3. SUMIFS — total budget by project and status in one cell

The Budget and Training Tracker I built needed a running total for each project that only counted confirmed spend — not estimates, not cancelled items. SUMIFS does exactly that.

Formula
=SUMIFS(C:C, A:A, "Project Alpha", B:B, "Confirmed")

C:C — the column with the dollar amounts to add up
A:A, "Project Alpha" — only rows where the Project column matches
B:B, "Confirmed" — and only rows where Status is Confirmed
Stack as many condition pairs as you need.

Confirmed spend: $0

4. Data validation + INDIRECT — dynamic dropdowns that update themselves

Static dropdowns break the moment someone adds a new instructor, project, or region. I use named ranges with INDIRECT so the dropdown list updates automatically whenever the source list changes — no one has to come to me to fix it.

Data Validation formula (in the source cell)
=INDIRECT(A1)

Named ranges — create a named range called "APAC" with APAC proctor names, "EMEA" with EMEA names, etc.
A1 — a cell where the user picks a region from a separate dropdown
INDIRECT — reads whatever text is in A1 and looks up the named range with that name
Result: picking "APAC" in A1 makes the second dropdown show only APAC proctors.

This mirrors how the dynamic dropdown behaves in the actual tracker.

5. Conditional formatting with a custom formula — visual status at a glance

A tracker with 80 rows and no color coding is just a wall of text. I use custom formula rules so rows color themselves based on status — no manual highlighting, no outdated color after a status change.

Custom formula (in conditional formatting, applied to the whole row)
=$D2="At risk"

$D2 — locks column D (status) but lets the row number move as the rule applies down the sheet
Set fill to amber for "At risk", red for "Blocked", green for "Complete"
The row re-colors the moment anyone updates the status cell — no manual step needed.
